# Jose Rizal University Course Portfolio

A static, responsive student course portfolio built with plain HTML, CSS, and
JavaScript. There is no build step or package installation.

## Run locally

Open `index.html` in a browser. The site also works when served from the root of
a GitHub Pages repository.

## Update portfolio details

Edit the `course` object at the top of `script.js`. Place images and other
portfolio assets under `assets/images`, and university logos under
`assets/logos`. Keep the existing relative paths when adding files so the site
continues to work on GitHub Pages.

## Publish with GitHub Desktop

This project contains more than 100 files, so do not upload it using GitHub's
browser file uploader, which limits a single upload to 100 files.

1. In GitHub Desktop, choose **File → Add Local Repository**.
2. Select this project folder.
3. If prompted to create a repository, create it in this existing folder.
4. Commit the files, then choose **Publish repository**.
5. On GitHub, open **Settings → Pages**, select the `main` branch and `/ (root)`.

The published page will be available at `https://<username>.github.io/<repository>/`.
